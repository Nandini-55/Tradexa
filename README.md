## 📖 Overview

**Tradexa** is a modern, full-stack virtual financial ecosystem designed to bridge the gap between paper trading and real-world capital management. 

Instead of traditional fiat dollars, Tradexa operates on an interactive **Virtual Coin (`🪙`) Economy**. Every new trader starts with **🪙 10,000 Virtual Coins** to simulate positions in US Equities (via Finnhub) and Indian Equities (NSE/BSE via Yahoo Finance). 

When traders run low on liquidity, **KuberX Virtual Bank** provides an instant, algorithmic credit vault where users can borrow virtual coins with transparent micro-interest rates, build their **Kuber Credit Score (500–850)**, and settle repayments with a single click in real-time.

## 🚀 Getting Started

### Prerequisites
Make sure you have installed:
- [Node.js](https://nodejs.org/) (v18.18+ or v20+ recommended)
- [Git](https://git-scm.com/)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### 1. Clone the Repository
```bash
git clone https://github.com/RihabhMishra-48/Virtual_trading.git
cd Virtual_trading
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env` file in the root directory and configure the following keys:

```env
NODE_ENV='development'
NEXT_PUBLIC_BASE_URL=http://localhost:3000

# MONGODB CONNECTION
MONGODB_URI=your_mongodb_connection_string

# BETTER AUTH
BETTER_AUTH_SECRET=your_better_auth_secret
BETTER_AUTH_URL=http://localhost:3000

# MARKET DATA (FINNHUB)
FINNHUB_API_KEY=your_finnhub_api_key
FINNHUB_BASE_URL=https://finnhub.io/api/v1

# QUANT AI ENGINE (TRADEXA DEEPQUANT MODEL API)
GEMINI_API_KEY=your_ai_engine_api_key

# INNGEST (OPTIONAL FOR LOCAL BACKGROUND JOBS)
INNGEST_EVENT_KEY=your_inngest_event_key
INNGEST_SIGNING_KEY=your_inngest_signing_key

# NODEMAILER (OPTIONAL FOR EMAIL NOTIFICATIONS)
NODEMAILER_EMAIL=your_email@example.com
NODEMAILER_PASSWORD=your_app_password
```

### 4. Run the Application
Start the Next.js development server:
```bash
npm run dev
```

*(Optional)* In a separate terminal, run Inngest dev server if you wish to run background cron workflows:
```bash
npx inngest-cli@latest dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deployment to Vercel

1. Push your latest code to your GitHub repository:
   ```bash
   git add .
   git commit -m "feat: complete Tradexa virtual trading and KuberX banking platform"
   git push origin master
   ```
2. Go to [Vercel Dashboard](https://vercel.com/) and click **New Project**.
3. Import your `Virtual_trading` GitHub repository.
4. Add all environment variables from `.env` in the Vercel **Environment Variables** settings.
5. Click **Deploy**! Your app will be live with high-performance edge rendering.
